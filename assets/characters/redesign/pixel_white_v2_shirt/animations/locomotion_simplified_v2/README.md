# Movimiento simplificado — versión 02

Decisión del usuario: usar pocos fotogramas que comuniquen claramente la acción. Evitar poses casi repetidas o fotogramas de relleno. No fijar ocho fotogramas por defecto. Proponer únicamente las poses necesarias, y obtener aprobación por animación antes de integrarla o continuar con otras acciones no solicitadas. No aplicar un límite obligatorio de tres a toda acción: la claridad visual determina cuántas necesita.

Caminar: tres poses seleccionadas del borrador anterior (00, 01, 02): paso extendido, apoyo y paso de la pierna. Tiempos ilustrativos 170/140/170 ms.
Correr: tres poses (00, 01, 03): zancada, apoyo comprimido y fase aérea. Tiempos ilustrativos 90/70/90 ms.
Dash: se conserva la versión de tres poses en ../dash_simplified_v2.
Salto: se mantiene la versión anterior para no cambiar una acción que el usuario no señaló en esta revisión.

Son ciclos estilizados mínimos para revisar, no una garantía de locomoción realista ni una aprobación final de la alternancia anatómica. Los PNG se reutilizan sin repintarlos ni deformarlos. Cada uno mide 128 × 192 con transparencia; las hojas de tres poses miden 384 × 192. Las versiones originales permanecen guardadas.

Abrir preview.html para revisar las cuatro acciones. La vista general anterior también apunta a estos nuevos ciclos. No se modificó el sprite activo, la física, los controles ni las velocidades del juego. Pendiente de aprobación.
