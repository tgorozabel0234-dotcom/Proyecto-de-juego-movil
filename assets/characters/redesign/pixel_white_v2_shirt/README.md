# Pixel art v2: camiseta bajo el chaleco

Cambio solicitado: camiseta oscura de manga corta bajo el chaleco existente,
cubriendo pecho, abdomen, hombros y parte de los brazos, con antebrazo tecnologico
visible. Se conservan el chaleco abierto, capucha, pelo blanco, pantalon y botas,
pose y lineas de neon cian/magenta. Basado en pixel_white_v1/preview_4x.png.

character_128x192.png: PNG RGBA transparente, exactamente 128 x 192.
preview_4x.png: ampliacion entera 512 x 768, vecino mas cercano, sin suavizado.
master_generated.png: imagen editada generativamente, conservada sin modificar.

Propuesta de redisenyo guardada en assets; no sustituye al jugador dentro del
juego. La version anterior permanece en pixel_white_v1 para comparar.
